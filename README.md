# Vehicle-Parking-V1

## Features Implemented

### User Features
- **Registration & Login**
- **Dashboard** showing active and past reservations
- **Search** for parking lots by location, address, or pincode
- **Book Slot** - reserves an available spot and updates its status
- **Release Parking** - calculates cost based on duration
- **Edit Profile**
- **View Summary**

### Admin Features
- **Admin Dashboard** - overview of all parking lots and occupancy
- **Add/Edit/Delete Lots**
- **Manage Spots** within each lot
- **Search Parking Lots**
- **View Registered Users**
- **View Parking Summary** - Tabular and Chart-based summaries

## Project Structure
•	**Flask** : Web framework for routing and server logic  
•	**Flask-SQLAlchemy** : To manage database operations
•	**SQLite** : Lightweight relational database
•	**Jinja2** : Template rendering
•	**HTML/CSS** : Frontend for templates
